## 1. 通用约定

### 1.1 域名(多域轮换, 以启动链下发为准)

| 域名 | 说明 |
|---|---|
| `https://api.atzxyff.com` | **当前实测主域**(推荐默认使用) |
| `https://apiw2.lhlamp.com` | 备用 |
| `https://apit2.lhlamp.com` | 备用 |
| `https://apiw.ygdj8.com` | 备用 |
| `https://cpi.atzxyff.com` | CPI 加密接口专用(GetDevice/GetConfig) |
| `https://aa99428-1394236515.cos.*.myqcloud.com` | host_and.jsonb 域名池文件(3 区域镜像) |

**域名池动态下发(实测 2026-08-17)**: 启动链第 1 步 `GET host_and.jsonb` 返回完整域名池(base64+混淆前缀 `a`, 见 01 文档 §1.1):
- **API 池**(4 个, 完全通用, 实测响应 md5 一致): `apiw2.lhlamp.com` / `apiw.ygdj8.com` / `apit2.lhlamp.com` / `api.atzxyff.com`(均 `/v3/`)
  - **域名选择**: 对池内各域名 `speedTest` **并行测速, 选最快固化**; 固化域名请求失败(超时/连接/5xx)时**重新测速轮询切换**(见 01 文档 §1.1.6; `client.py` 已封装 `fetch_api_pool()` / `resolve_fastest_host()` / 自动切换)
- **CPI 池**(独立, 不可与主 API 混用): `cpih/cpiw.ygdj8.com` / `cpiw.lhlamp.com` / `cpi.atzxyff.com`(均 `/API/`)
- **封面 CDN 池**(5 组): `cover`/`self_cover`/`aops_cover`/`com_cover`/`9_cover`(vstonlook.com、yjior.com、humenhd.com 等)
- 其余: 支付 `PAY_API`、WebSocket `WS_API`、统计 `track`(piwik)、市场 `MKT_API`/`GTAG_API`/`INSTALLED_API`

### 1.2 统一请求头(所有 /v3 接口)

```
Authorization: Bearer <JWT>        # 认证头, 必须先 GET /v3/202306/visitor 获取(见开屏页)
Accept: application/json
api_time_out_header: 30             # App 自定义超时头(秒)
User-Agent: okhttp/3.12.10
Content-Type: application/json; charset=utf-8   # 仅 POST 请求携带
```

**关键**: 请求/响应**全部明文 JSON**, 无签名头、无时间戳头。认证只靠 `Authorization` 头。

### 1.3 认证流程(访客 token)

```bash
# 1. 获取 JWT
curl -X GET 'https://api.atzxyff.com/v3/202306/visitor?device_id=f413d4ef3f36c416&platform=android&channel_code=Night_Official_SPapk' \
  -H 'Accept: application/json' -H 'api_time_out_header: 30' -H 'User-Agent: okhttp/3.12.10'
# 响应: {"token":"eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9.eyJ..."}

# 2. 之后所有请求带认证头
curl 'https://api.atzxyff.com/v3/xxx' \
  -H 'Authorization: Bearer eyJ0eXAiOiJKV1QiLCJhbGciOiJIUzI1NiJ9.eyJ...' \
  -H 'Accept: application/json' -H 'User-Agent: okhttp/3.12.10'
```

### 1.4 响应通用结构

| 形态 | 说明 | 示例接口 |
|---|---|---|
| `{"data": {...}}` | data 包裹对象 | `/v3/android`、`/v3/main_screen` |
| `{"data": [...]}` | data 包裹数组 | `/v3/country_codes` |
| 直接对象 | 无 data 包裹 | `/v3/new/subscriptions`、`/v3/inform` |
| 纯文本 | 非 JSON | `/v3/speed_test` → `OK` |

### 1.5 分页规律(重要)

| 参数 | 说明 | 示例 |
|---|---|---|
| `next` | 游标分页, 0 起, 每页 10-20 条; 响应含 `next` 字段, `null`=无更多 | `?next=0` → `?next=10` |
| `page` | 页码分页, 1 起(漫画/筛选/动画) | `?page=1` |
| `ts` | 按日期翻页(Unix 天), 用于"最新"按天查 | `?next=0&ts=1786636800` |
| `limit` | 每页条数(部分接口) | `?limit=20` |

### 1.7 加密接口族(3 类, 详见各文档)

| 族 | 接口 | 说明 |
|---|---|---|
| videoCrypt | `/v3/video/{code}/info` 响应 | base64 密文 → 需 AES 解密(见 05 文档) |
| CPI | `/API/GetDevice`、`/API/GetConfig` | 请求/响应均密文 → 需 AES 加密+解密(见 01 文档) |
| 播放流 | m3u8 / key / ts | 由 info 解密结果直接下发, 无需自行拼接(见 05 文档) |
