# AVNight API 接入文档 · 模块四：分类

> 覆盖: 分类页四大部分(AV女优 / 视频类型 / 驻站主编 / 油管视频)。请求头统一: `Authorization: Bearer <JWT>` + `Accept: application/json` + `User-Agent: okhttp/3.12.10`。

---

## 1. AV 女优

### 1.1 热门女优
| 项 | 值 |
|---|---|
| 方式 | `GET` / `https://api.atzxyff.com/v3/category/top_actors` |

### 1.2 女优列表(带筛选)
| 项 | 值 |
|---|---|
| 方式 | `GET` / `https://api.atzxyff.com/v3/category/actors` |

**请求参数(query)**:

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `actor_type` | string | 是 | `long`(日本) / `ngs`(国产) |
| `category` | string | 是 | `1`(全部) / `2`(精选) / `3`(最新) / `4`(畅销) |
| `age` | string | 是 | `ALL` / `18-25` / `26-35` / `36+` |
| `cup` | string | 是 | `ALL` / `A` / `B` / `C` / `D` / `E` / `F` / `G+` |
| `next` | int | 是 | 分页 0 / 100 / 200 |

**示例**:
```
GET /v3/category/actors?actor_type=ngs&category=1&age=ALL&cup=ALL&next=0
GET /v3/category/actors?actor_type=long&category=2&age=18-25&cup=D&next=0
```

### 1.3 某个女优详情与作品
```
GET /v3/result/popular_week/video/general                 # 本周淫幕亮点
GET /v3/actor/93/videos?actor_type=long&limit=20&next=0   # 女优分页视频(93=女优id)
```
| 参数 | 说明 |
|---|---|
| `actor_type` | `long`(日本) / `ngs`(国产) |
| `limit` | 每页条数(20) |
| `next` | 分页游标 |

## 2. 视频类型

### 2.1 分类总览
| 项 | 值 |
|---|---|
| 方式 | `GET` / `https://api.atzxyff.com/v3/categorys` |

**响应体字段**(取对应字段即可):
```json
{
  "categorys": [ ... ],          // 热门视频类型
  "recommend_genres": [ ... ],   // 今日推荐
  "japanAV": [ ... ],            // 日本AV
  "short_video": [ ... ],        // 短视频
  "special_video": [ ... ]       // 特殊视频
}
```

### 2.2 视频筛选神器
| 项 | 值 |
|---|---|
| 方式 | `GET` / `https://api.atzxyff.com/v3/filter/category` |

**响应体字段**:
| 字段 | 说明 |
|---|---|
| `eu_us_studio` | 欧美视频 |
| `japan_av` | 日本AV |
| `ngs_genre` | 国产原创 |
| `short_genre` | 短视频 |

### 2.3 筛选结果视频列表
| 项 | 值 |
|---|---|
| 方式 | `GET` / `https://api.atzxyff.com/v3/filter/category/{type}/{id}/videos` |

**路径参数**: `type`(japan_av / eu_us_studio / ngs_genre / short_genre)、`id`(分类id, 用 `*` 表示不筛选)
**请求参数**: `page=1`、`order_by=onshelf_tm`(上架时间) / `collect_count`(人气收藏) / `watch_count`(小众口味)

**示例**:
```
GET /v3/filter/category/japan_av/*/videos?page=1&order_by=onshelf_tm
GET /v3/filter/category/japan_av/125/videos?page=1&order_by=collect_count
```

### 2.4 点击标签获取标签视频
```
GET /v3/result/popular_week/video/general                          # 本周淫幕亮点
GET /v3/genre/125/videos?video_type=ngs&video_origin=ALL&next=0    # 分页视频
```
| 参数 | 说明 |
|---|---|
| `video_type` | `ngs`(国产) / `long`(日本) 等 |
| `video_origin` | `ALL` / `DINABZ` / 具体来源 |
| `next` | 分页游标 |

## 3. 驻站主编

### 3.1 主编列表(分页)
| 项 | 值 |
|---|---|
| 方式 | `GET` / `https://api.atzxyff.com/v3/topics` |
| 参数 | `next=0`(取 0-5 共 6 条) / `next=6`(取 6-11 条) |

### 3.2 某主编的视频
```
GET /v3/result/popular_week/video/general        # 本周淫幕亮点
GET /v3/topic/278/videos?next=0                  # 分页视频(278=主编id)
```

## 4. 油管视频

### 4.1 油管频道
| 项 | 值 |
|---|---|
| 方式 | `GET` / `https://api.atzxyff.com/v3/yt/studios` |
| 参数 | `next=0` |

### 4.2 具体频道视频列表
| 项 | 值 |
|---|---|
| 方式 | `GET` / `https://api.atzxyff.com/v3/ytstudio/{id}/videos` |
| 参数 | `next=0` |

**示例**: `GET /v3/ytstudio/51/videos?next=0`

### 4.3 油管热门 / 最新
```
GET /v3/yt/hot/videos
GET /v3/yt/new/videos?next=0        # next=0 拉 0-19, next=20 拉 20-39
```

## 5. 分类页调用组合示例

```python
from client import ApiClient
c = ApiClient(); c.get_visitor_token(device_id="f413d4ef3f36c416")

# 女优筛选(日本/国产 × 全部分类)
c.get("/v3/category/actors", params={"actor_type": "long", "category": "1", "age": "ALL", "cup": "ALL", "next": 0})

# 视频类型总览
data = c.get("/v3/categorys").json()

# 筛选排序三变体
for order in ["onshelf_tm", "collect_count", "watch_count"]:
    c.get("/v3/filter/category/japan_av/*/videos", params={"page": 1, "order_by": order})

# 主编分页
c.get("/v3/topics", params={"next": 0})
c.get("/v3/topics", params={"next": 6})

# 油管
c.get("/v3/yt/studios", params={"next": 0})
c.get("/v3/yt/new/videos", params={"next": 0})
```
