# AVNight API 接入文档 · 模块五：视频详情页与播放链路

> 覆盖: 视频详情(加密)/ 相关推荐 / 高光片段 / 完整播放链路(m3u8 → AES密钥 → TS分片 → 下载)。

## 1. 视频详情(核心, 响应为密文)

| 项 | 值 |
|---|---|
| 请求方式 | `GET` |
| URL | `https://api.atzxyff.com/v3/video/{code}/info` |
| 功能 | 视频详情 + 播放源(响应体为 base64 密文, 需解密) |

**路径参数**:
| 参数 | 说明 |
|---|---|
| `code` | 视频唯一码。来源: ① 列表接口返回的 `code` 字段(如 `MISM-325-`、`NAMH-072`、`zangJingVideo-11461`、`ANIMATION-00036_01`); ② 各模块详情页 |

**请求参数(query)**:
| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `cdn` | string | 是 | CDN 标识, 实测 `c`; 值来自 `/v3/android` 的 `CdnBean.cdn` |

**请求头**: `Authorization: Bearer <JWT>`(必填, 否则 401)

**响应体**: `content-type: text/html`, body = **base64 密文**(6424B), 响应头 `x-avnight-time` = 服务端时间戳(秒)。

### 1.1 解密算法(videoCrypt, 已逆向验证)

```
ts     = 响应头 x-avnight-time × 1000    # 秒 → 毫秒
日期串 = SimpleDateFormat("yyyyMMdd-HHmmss", GMT+08:00).format(new Date(ts))   # 如 20260815-132553
密钥串 = "a@v*9$QAQ" + 日期串             # 盐在前!
key    = MD5hex(密钥串).encode()          # 32B ASCII hex -> AES-256
iv     = (日期串 + "#").encode()          # 16B ASCII
明文   = AES-256-CBC-PKCS7(base64decode(密文), key, iv)
```

```json

    "thumb64": "https://hlcl6.vstonlook.com/data/adult-videos/NAMH-072/thumb/NAMH-072/w",
    "video_type": "long",
    "exclusive": false,
    "is_ai_chinese_dubbing": false,
    "genres": [{"sid": 421, "name": "乱交", "video_type": "long"}],
    "onshelf_tm": 1786107601,
    "breast_coin_video_info": {"is_breast_coin_video": false},
    "sources": {                          // ★ 播放源(完整 URL, 直接可用)
      "240": "https://api.atzxyff.com/v3/NAMH-072/cloudfront/240.m3u8?k=136a6be7...&t=1786712120&token=bearer%20<JWT>",

```

### 1.3 Python 解密示例

```python
import sys; sys.path.insert(0, "/Users/weifeng/PycharmProjects/Spider/avnight_api")
from client import ApiClient
from crypto import video_crypt_decrypt   # 项目已封装

c = ApiClient(); c.get_visitor_token(device_id="f413d4ef3f36c416")
r = c.get("/v3/video/MISM-325-/info", params={"cdn": "c"})

# 取响应头时间戳(秒→毫秒)
ts_ms = int(r.headers["x-avnight-time"]) * 1000
plain = video_crypt_decrypt(ts_ms, r.text)     # 明文 JSON
video = json.loads(plain)["video"]
m3u8_url = video["sources"]["240"]             # ★ 直接可用的播放地址
```

## 3. 完整播放链路(m3u8 → 密钥 → 分片)

> ⚠️ 原则: **所有 URL 均来自 `sources.240`(m3u8) 与播放列表内容解析, 不要自行拼接。**

### 3.1 播放列表 m3u8

**URL 来源**: 直接取 §1.2 的 `video.sources.240` 整串。

```
GET https://api.atzxyff.com/v3/MISM-325-/cloudfront/240.m3u8?k=c938ea12...&t=1786886959&token=bearer%20<JWT>
```

**URL 参数说明**(服务端下发, 客户端原样使用):
| 参数 | 说明 |
|---|---|
| `k` | 播放签名(hex) |
| `t` | 下发时间戳(秒) |
| `token` | 播放专用 JWT(URL 编码 `bearer%20<JWT>`), 与请求头 Authorization 不同 |

**响应体**(AES-128 加密 HLS):
```
#EXTM3U
#EXT-X-VERSION:4
#EXT-X-PLAYLIST-TYPE:VOD
#EXT-X-KEY:METHOD=AES-128,URI="https://cel.hscammq.com/apen/MISM-325-/240/key.php?k=41a13536...&t=1786887102",IV=0x0DF9E44ABA65612FD53272ADDF17B7FB
#EXT-X-TARGETDURATION:6
#EXTINF:6.006000,
https://cel.hscammq.com/apen/MISM-325-/240/ts/MISM-325--0.ts?k=3d63d0f6...&t=1786887102
...
#EXT-X-ENDLIST
```
(实测 1602 分片, 总时长 160 分钟, 204KB)

### 3.2 AES-128 密钥

**URL 来源**: 从 m3u8 解析 `#EXT-X-KEY` 行的 `URI="..."`。

```
GET https://cel.hscammq.com/apen/MISM-325-/240/key.php?k=41a13536a59d85d0f0544fe16628433e&t=1786887102
```

**响应体**: 16 字节二进制密钥(hex 如 `0df9e44aba65612fd53272addf17b7fb`, 与 m3u8 的 IV 一致)。

### 3.3 TS 视频分片

**URL 来源**: 从 m3u8 逐条提取(`#EXTINF` 后一行)。每条分片 `k`/`t` 独立签名。

```
GET https://cel.hscammq.com/apen/MISM-325-/240/ts/MISM-325--0.ts?k=3d63d0f639873e72fa83b0076c6bd386&t=1786887102
```

**响应体**: AES-128 加密的 MPEG-TS(解密后首 4 字节 `47 40 00 10`)。实测分片 300-520KB, 无分片数限制。

### 3.4 时效性(重要)

| 项 | 实测值 |
|---|---|
| 有效期 | **6 小时**(m3u8 URL 的 `t` 与 token.exp 之差恒为 21600s) |
| 过期表现 | m3u8 / TS 返回 401 |
| 处理 | 过期后**重新请求** `GET /v3/video/{code}/info` 获取新 sources |

> ⚠️ **应"即时获取即时使用"**, 不要提前批量拉取播放地址。
