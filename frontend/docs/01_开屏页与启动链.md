### 1.1.2 响应解密(重要)

> ⚠️ 响应体 = base64(JSON), 且**首字符 `a` 是混淆前缀**(实测所有该类资源都有), 解码前必须跳过。

```python
import base64, re

def smart_b64decode(data: bytes) -> bytes:
    s = data.strip().decode("utf-8", "replace")
    s = re.sub(r"\s", "", s)
    if s.startswith("a"):            # 混淆前缀(实测必有)
        s = s[1:]
    s = s.rstrip("=")
    s += "=" * (-len(s) % 4)
    return base64.b64decode(s)

json_text = smart_b64decode(resp.content)   # -> bytes, 再 json.loads
```

### 1.1.4 域名差异与通用性备注(全部实测)

1. **3 个 COS URL 内容完全相同**——同一文件的多区域/加速镜像(md5 一致), 取任一即可
2. **API 池 4 域名完全通用**——实测 `speed_test` 全 `OK`、visitor token 跨域名可用、同一接口(如 `/v3/new/top/videos`)两个域名响应 **md5 完全一致** → 接入时固定任一, 失败轮换即可
3. **CPI 池与主 API 池相互独立**——CPI 接口(`/API/GetDevice|GetConfig`)只能用 CPI 域名(`cpi*.ygdj8.com` 等), 主 API 域名不提供 CPI 服务, 反之亦然
4. **封面 CDN 池 5 组**——`cover`(演员图) / `self_cover`(视频封面) / `aops_cover` / `com_cover` / `9_cover`; 列表接口返回的 `cover64`/`thumb64` URL 由这些域名提供
5. **speedTest 探测响应也是 base64 + `a` 前缀**——`monitor/p` 返回 1×1 PNG、`cover` 的 actor 探测返回 JPEG, 解码方式与 host_and.jsonb 相同(见 1.1.2)
6. 域名池由服务端动态下发, 可能随时增删——接入方应"启动时拉取 + 缓存 + 失败轮换"

### 1.1.6 域名选择策略(speedTest 测速选优 + 失败轮询)

> 接入方应"动态选域名", 不要写死。实测 4 个 API 域名完全通用(响应 md5 一致), 选哪个主要看网络质量。

**流程**:
1. 启动时拉取 `host_and.jsonb`(见 1.1.1) → 取 `API` 字段的 4 个 `apiHost`
2. 对每个域名请求其 `speedTest` URL(如 `https://apiw2.lhlamp.com/v3/speed_test`)测速, **返回 `OK` 且响应最快者固化为本次会话 API 域名**
3. 固化域名**请求失败**(超时/连接错误/5xx/SSL 异常)时 → 重新对 `API` 池测速选最快 → 切换, 循环兜底

**实现示意**:
```python
import requests, time

HOST_URLS = "https://aa99428-1394236515.cos.ap-nanjing.myqcloud.com/host_and.jsonb"

def fetch_api_pool() -> list[dict]:
    """拉 host_and.jsonb -> 解码(跳过 'a' 前缀) -> API 池"""
    # 见 1.1.2 的 smart_b64decode
    r = requests.get(HOST_URLS, timeout=10)
    j = json.loads(smart_b64decode(r.content))
    return j["API"]                                   # [{apiHost, speedTest} x4]

def fastest_host(pool: list[dict], timeout: float = 3.0) -> str:
    """对每个域名 speedTest 测速, 返回最快 apiHost(去掉尾 /v3/ 得到根域名)"""
    best, best_ms = None, 99999.0
    for item in pool:
        t0 = time.time()
        try:
            requests.get(item["speedTest"], timeout=timeout)
            ms = (time.time() - t0) * 1000
            if ms < best_ms:
                best, best_ms = item["apiHost"].rstrip("/"), ms
        except Exception:
            continue                                    # 失败跳过
    return best or "https://api.atzxyff.com"            # 全失败用默认

# 会话域名 = 测速最快
host = fastest_host(fetch_api_pool())

# 请求失败时重新测速轮询
try:
    r = requests.get(host + "/v3/new/videos", params={"next": 0}, timeout=10)
except Exception:
    host = fastest_host(fetch_api_pool())               # 重新选最快
    r = requests.get(host + "/v3/new/videos", params={"next": 0}, timeout=10)
```

> 项目已封装: `client.py` 新增 `fetch_api_pool()` / `resolve_fastest_host()` / 请求失败自动切换域名(见 00 文档 §1.1)。

## 1.2 CPI 加密接口(GetDevice / GetConfig)

> ⚠️ 本族接口**请求/响应体均为 AES-256-CBC 密文**(base64), 与其它 /v3 接口完全不同。
> 完整加解密已逆向并封装在 `crypto.py`, 项目内直接调用即可。

### 1.2.1 加解密方案(已逆向验证)

```
盐     = "~WonWonIsOnFire~+"
时间串 = datetime.fromtimestamp(ts_unix, GMT+8).strftime("%Y%m%d-%H%M%S")   # 15字节, 如 20260816-211048
key    = MD5hex(盐 + 时间串).encode()      # 32B ASCII hex -> AES-256
iv     = 时间串.encode().ljust(16, b"\x00") # 15B + 0x00 (注意不是 '#')
算法   = AES-256-CBC-PKCS7, 密文 base64
响应时间戳 = 响应时刻(与请求可能差 1~2 秒), 解密带 ±90s 容错
```

**Python 用法**:
```python
from crypto import cpi_encrypt, cpi_decrypt
enc_body = cpi_encrypt('{"type":"A"}', int(time.time()))
plain, ts_str = cpi_decrypt(resp_text, ts)   # 自动处理时间戳容错 + \x01 还原
```

## 2. 完整启动链顺序(实测)

```
Step1  GET host_and.jsonb(3 COS 镜像)          → base64+混淆前缀, 解码得域名池(见 1.1)
Step2  GET /v3/speed_test(对 API 池各域名测速)  → "OK"(选最快域名)
Step3  GET /v3/android                        → 全局配置(含 CdnBean.cdn)
Step4  GET /v3/202306/visitor                 → JWT
Step5  GET /v3/202212/folder/{get|collection/get|comic/get}
Step6  GET /v3/personal/menu
Step7  GET /v3/inform
Step8  POST /v3/mkt_report                    → 事件上报
Step9  POST /API/GetDevice                    → user_id + token(加密)
Step10 POST /API/GetConfig                    → 落地页配置(加密, 需 x-avnight-string)
```
