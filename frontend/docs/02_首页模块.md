# AVNight API 接入文档 · 模块二：首页

> 覆盖: 首页聚合 + 全部板块(AI中配 / AI无码 / 奶币福利 / 最新 / 热门 / 动漫 / 短视频 / VIP色圈 / 中字无码)。
> 除特别标注外, 请求头均为 `Authorization: Bearer <JWT>` + `Accept: application/json` + `api_time_out_header: 30` + `User-Agent: okhttp/3.12.10`。

## 2.1 首页子 Tab 路由(PageMenu 驱动)

> ⚠️ **首页顶部子 Tab(订阅/精选/AI中配/.../中字无码)的请求路径不是写死的, 而是来自 `/v3/android` 响应的 `data.PageMenu` 字段。**
> 拼接规则: `GET {API域名}/v3/{path}?{各Tab参数}`(域名见 01 文档 §1.1, 各 Tab 参数见后续小节)。

### 2.1.1 PageMenu 完整定义(实测 /v3/android)

### 2.1.2 拼接规则与特殊 Tab 说明

| Tab | path | 拼接后的请求 | 说明 |
|---|---|---|---|
| 订阅(id=1) | `new/subscriptions/videos` | `GET /v3/new/subscriptions/videos?next=0` | 关注聚合视频 |
| 精选(id=2) | `videos/index/full/0` | ⚠️ **不直接请求** | 该 path 只是客户端路由标识, **真实数据来自 `/v3/main_screen` 的 `ace` 板块**(见 2.3) |
| AI中配(id=3) | `chinese_dubbing` | → `/v3/chinese_dubbing/mainscreen`(见 2.4) | — |
| AI无码(id=4) | `clean_mosaic` | → `/v3/clean_mosaic/leaderboard` 等(见 2.5) | — |
| 奶币福利(id=5) | `breast_coin_videos` | → `/v3/breast_coin_video/*`(见 2.6) | ⚠️ path 与接口名略有差异(复数→单数) |
| 最新(id=6) | `new/videos` | `GET /v3/new/videos?next=0`(见 2.7) | — |
| 热门(id=7) | `new/top/videos` | `GET /v3/new/top/videos?next=0&type=...`(见 2.8) | — |
| 动漫(id=8) | `comic` | `GET /v3/comic`(见 2.9) | — |
| 短视频(id=9) | `video_clip` | `GET /v3/video_clip?tz=Asia/Taipei`(见 2.10) | — |
| VIP色圈(id=10) | `vip_main_screen` | `/v3/vip_main_screen` | 旧版入口 |
| VIP色圈2024(id=11) | `vip_main_screen_2024` | `GET /v3/vip_main_screen_2024`(见 2.11) | **新版实际使用** |
| 中字无码(id=12) | `videos/tagged` | `GET /v3/videos/tagged?next=0`(见 2.11) | — |

### 2.1.3 代码建议(从 PageMenu 取值拼接)

```python
from client import ApiClient
c = ApiClient(); c.get_visitor_token(device_id="f413d4ef3f36c416")

# 1. 取 PageMenu
cfg = c.get("/v3/android").json()["data"]
page_menu = {m["name"]: m["path"] for m in cfg["PageMenu"]}

# 2. 按 name 拼接请求(订阅/精选特殊处理)
def tab_request(name: str, extra_params: dict | None = None):
    path = page_menu[name]
    if path == "videos/index/full/0":        # 精选 -> 走 main_screen.ace
        return c.get("/v3/main_screen", params={"platform": "android"})
    if name == "奶币福利":                    # path 与接口差异(复数->单数)
        path = "breast_coin_video"
    return c.get(f"/v3/{path}", params=extra_params or {})

# 3. 例: 最新 Tab
r = tab_request("最新", {"next": 0})         # GET /v3/new/videos?next=0
```

**示例**: `https://apit2.lhlamp.com/v3/new/videos?next=0` = 域名(`apit2.lhlamp.com/v3/`) + PageMenu[最新].path(`new/videos`) + 参数(`?next=0`)。

## 2.2 首页聚合(一屏全板块)

| 项 | 值 |
|---|---|
| 请求方式 | `GET` |
| URL | `https://api.atzxyff.com/v3/main_screen` |
| 功能 | 首页全部板块数据(37 万字节大响应) |

**请求参数(query)**:

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `platform` | string | 是 | `android` |

**响应体**(`{"data":{...}}`, 顶层板块):
```
ace, actors, ai_chinese_dubbing, assemble_actors, assemble_actors_v2,
breast_coin_classic_video, company, deepfake_actor, deepfake_collection,
deepfake_video, featured_actors, koubei, onlyfans, popular_classic,
top_weeks_videos, topics, video_category, xchina, yt, zhibo
```

**各板块内容**:
| 板块 key | 内容 | 条目示例 |
|---|---|---|
| `ace` | 精选(含 niche/shufu/stan 子板块) | `{"niche":[{code:"ONLYFANS-14923",...}]}` |
| `actors` | 演员聚合 | — |
| `ai_chinese_dubbing` | AI 中配 | — |
| `onlyfans` | OF 博主 | — |
| `popular_classic` | 经典 | — |
| `top_weeks_videos` | 本周热门 | — |
| `company` | 厂商 | — |
| `deepfake_*` | AI 换脸 | — |
| `breast_coin_classic_video` | 奶币经典 | — |
| `yt` / `xchina` / `zhibo` | 油管 / XChina / 直播 | — |

**条目字段**(视频 object, 同 00 文档 §1.6):
```json
{
  "code": "ONLYFANS-14923",
  "cover64": "https://shlcl-4.vstonlook.com/onlyfans/ONLYFANS-14923/ONLYFANS-14923/w",
  "duration": 3128,
  "exclusive": true,
  "has_intro": true,
  "is_ai_chinese_dubbing": false,
  "onshelf_tm": 1685578140,
  "tags": ["of博主"],
  "genres": [{"name": "OnlyFans", "sid": 13801, "video_type": "ngs"}],
  "actors": [{"name": "台北娜娜", "sid": 38766, "video_count": 58}]
}
```

**Python 示例**:
```python
c = ApiClient(); c.get_visitor_token(device_id="f413d4ef3f36c416")
r = c.get("/v3/main_screen", params={"platform": "android"})
data = r.json()["data"]
for v in data["ace"]["niche"]:          # 精选板块
    print(v["code"], v.get("title", ""))
```

## 3. 首页常见调用组合(实测样例)

```python
from client import ApiClient
c = ApiClient(); c.get_visitor_token(device_id="f413d4ef3f36c416")

# 新片 Top(今日/昨日/日本AV/短视频 四变体)
for t in ["", "day_prev", "jp_av", "short_video"]:
    r = c.get("/v3/new/top/videos", params={"next": 0, "type": t})

# 奶币分区
r = c.get("/v3/breast_coin_video/1", params={"is_collections": 0, "order": "hot", "next": 0})

# 去码排期四变体
for s in ["today", "yesterday", "this_week", "last_week"]:
    r = c.get("/v3/clean_mosaic/schedule", params={"sort": s, "next": 0})

# AI中配合集三变体
for t in ["new", "hot", "recommend"]:
    r = c.get("/v3/chinese_dubbing/collections", params={"type": t, "order_by": "DESC", "next": 0})
```
